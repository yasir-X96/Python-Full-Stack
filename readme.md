# Python
## Datatypes and variables
### Rules for variable Name Declaration
- can start with letters also with underscore
- cannot start with number
- no spaces allowed in between names
- no special characters 
- use meaning names
- For constants use **capital case**
- Don't use Reserved Keywords

* Integer
* Float
* String
* bool
* list 
* dict
* tuple
* Set
* Nonetype
* byte
